## [ ] 触屏上滑 / 左滑翻页（暂不推进）

状态：**仅评估完成，已搁置，暂不实现。**

### 背景

阅读器页模式的翻页输入目前只有两条路径：

- 键盘方向键 / PageUp / PageDown（`frontend/src/views/ReaderView.tsx` 的 keydown 处理）；
- `viewport` 上的 `wheel`（含精密触控板双指滚动），带 160ms 手势间隔、48px 累积阈值、320ms 防连翻。

触屏（`pointerType === 'touch'`）完全没有处理；`.viewport` 是 `cursor: text`、文字层保留 `user-select`，
长按会走 WebView2 原生选词与选择手柄。`.turn-zone` 是左右各 12% 的 `<button onClick>`。

### 可行性结论

**可以支持，只动前端，不需要改 Go / 协议层。** Windows 上的 Wails 用 WebView2（Chromium 内核），
触摸会正常产生 `pointerdown` / `pointermove` / `pointerup`。

关键认知：**「上滑」和「长按选择」在系统层没有两个可区分的事件。** 长按选词是指针按下后约 500ms 内的
静止手势，由浏览器自己完成选区与手柄渲染。正确做法是自己维护指针状态机，判定为滑动前不动作；
判定为长按时完全不干预，让原生选区照常工作。

### 区分规则（指针状态机）

| 判据 | 取值 | 说明 |
|---|---|---|
| 移动容差 slop | 8–10 px | 超过即进入手势候选，此后不再算长按 |
| 长按判定 | 静止 < slop 且 ≥ 450–500ms | 进入长按态后不干预，交给原生选区 |
| 滑动生效距离 | 48 px（与 wheel 阈值一致） | 也可用「24px + 速度 > 0.3 px/ms」的 flick |
| 主轴 | `abs(dx) > abs(dy) * 1.2` | 否则按纵向处理 |
| 方向 | 上滑 / 左滑 → 下一页；下滑 / 右滑 → 上一页 | 横向与现有 `turn(±1)` 语义一致 |
| 点击抑制窗口 | 350ms | 滑完落在 `.turn-zone` 上会补发 click，必须吞掉 |

流程：

1. `pointerdown`：只接受 `pointerType === 'touch'`、`isPrimary`、当前无第二根手指；记录起点与时间。
   **不调用 `preventDefault()`**，否则破坏长按选词。
2. `pointermove`：活动指针数 > 1 直接放弃（捏合 / 双指）；位移 > slop 切到 Pan 并记录末点用于测速；
   位移始终 ≤ slop 且到时 → 标记 LongPress。
3. `pointerup`：仅在 Pan 态判断主轴、方向、阈值，然后调用现有 `turn(±1)`；随后置 `suppressClickUntil`。
4. `pointercancel`：放弃。
5. 否决条件：`window.getSelection()?.isCollapsed === false`（用户正在选字）、`ctrlKey`、
   `target.closest('button,a,input,img,.theme-panel,.toc-panel')`。
6. 只在 `mode === 'page'` 且非打字 / 聊天皮肤下启用；`scroll` 模式保留原生滚动。

### CSS 配合

```css
.viewport { touch-action: none; }             /* 翻页模式：不让浏览器接管手势 */
.viewport.scroll-mode { touch-action: pan-y; } /* 滚动模式：保留原生滚动 */
```

`touch-action` 只影响滚动 / 缩放，不会关掉长按选词，这是它能与选区共存的原因。

### 已知坑

1. **合成 click 导致双重翻页**：手指从中间滑到右侧 12% 区域抬起会触发 `.turn-zone.right` 的 click，
   必须在捕获阶段用 `suppressClickUntil` 吞掉，否则一次滑动翻两页。
2. **选区进行中禁止翻页**：长按拖动扩展选区后，`pointerup` 位置可能满足滑动阈值；
   靠 `getSelection().isCollapsed` 否决一次即可，**不要清空用户的选区**。
3. **`touch-action: none` 与长按选词的关系需实测**：Chromium 中通常不影响，若实测受影响，
   退回 `pan-y`（页模式没有可滚动容器，浏览器一般不会取消 pointer 流）。
4. 触屏双指与触控板双指不是同一条事件路径（前者 pointer、后者 wheel），互不干扰，不要复用同一套阈值。
