# UI 动效评估与规范（2026-10-30）

## 1. 结论

当前界面已经有少量动效，但分散、时长和缓动不统一，且**没有统一的“进入/退出”语义**：

- 阅读器：翻页 220ms、淡入 200ms、工具栏 220ms、目录 200ms、外观面板 160ms。
- 通用控件：按钮 120–160ms、输入框 150ms、开关 180ms、书封 200ms。
- 反馈：Toast 只有进入、没有退出；同步状态只有侧栏 spinner。
- 页面切换、设置页签切换没有任何过渡。
- 没有 `prefers-reduced-motion` 适配。

本次采用“**短、轻、只动 transform/opacity**”的原则，补齐页面进入、页签切换、导航选中、Toast 退出和同步脉冲，同时提供减少动态效果的模式。

## 2. 动效令牌

统一定义在 `frontend/src/styles/base.css`：

```css
--ease-standard: cubic-bezier(0.2, 0.8, 0.3, 1);
--ease-out: cubic-bezier(0.16, 1, 0.3, 1);
--ease-in: cubic-bezier(0.4, 0, 1, 1);
--dur-fast: 120ms;
--dur-base: 180ms;
--dur-slow: 240ms;
```

规则：

- 装饰性动效不超过 240ms。
- 进入用 `--ease-out`，退出用 `--ease-in`，状态切换用 `--ease-standard`。
- 只动画 `opacity` 与 `transform`，不动画 `width/height/top/left`，避免触发布局。
- 阅读正文本身不做入场动画；正文的变化只由翻页动效承担。

## 3. 位置评估

| 位置 | 动效 | 时长 / 缓动 | 结论 |
|---|---|---|---|
| 页面切换（书架、详情、设置、统计） | 淡入 + 上移 6px | 180ms / ease-out | 已实现。只触发一次，不影响滚动位置 |
| 设置页签切换 | 区块淡入 | 180ms / ease-out | 已实现。比整页滑动更克制 |
| 侧栏当前项 | 左侧强调条展开 | 120ms / ease-out | 已实现。替代整行缩放 |
| Toast | 进入上移淡入，结束前淡出 | 180ms 进 / 220ms 出 | 已实现。错误提示停留更久 |
| 标题栏同步状态 | 品牌圆点呼吸 | 1.6s / ease-standard | 已实现。只在 `shelfState=loading` 时出现 |
| 阅读器工具栏显隐 | 淡入 + 位移 | 现有 220ms | 保留。阅读器内不加速 |
| 翻页 | 滑动 / 淡入 | 现有 220ms | 保留。已有独立开关 |
| 目录 / 外观面板 | 滑入 / 轻微缩放 | 180–240ms | 已统一缓动 |
| 按钮、输入、开关 | 背景 / 位移 | 120–180ms | 保留现有，改用令牌 |
| 加载 spinner | 匀速旋转 | 750ms linear | 保留。减少动态模式下降速 |
| 打字光标 | 闪烁 | 1.05s steps | 保留。减少动态模式下改为常亮 |
| 书封加载 | 图片淡入 | 建议 P1 | 需要图片 `onLoad` 状态，暂未做 |
| 书架骨架屏 | 微光扫过 | 建议 P1 | 目前用 spinner，先不引入持续闪烁 |
| 路由横向滑动 | 大位移 | 不建议 | 桌面端容易晕，且与阅读方向冲突 |
| 正文逐字/逐段入场 | 文字位移 | 不建议 | 干扰阅读、影响分页测量 |
| 常驻装饰性闪烁 | 无限闪烁 | 不建议 | 只允许“同步中”这种有明确状态的短时呼吸 |

## 5. 可访问性与性能

- 所有装饰性动效都受 `prefers-reduced-motion` 控制。
- 闪烁只使用低对比度透明度呼吸，频率 1.6s，远低于 3Hz 的光敏阈值。
- 不使用整页横向滑动、缩放正文、模糊动画。
- 不给长列表逐项加延迟，避免上百本书同时排队动画。
- 所有新增动画只改变 `opacity` / `transform`，不触发重排。
