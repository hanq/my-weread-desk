# 触控板手势评估（2026-10-30）

## 结论

**支持。** Windows 上的 WebView2 会把精密触控板的双指滚动映射为标准的 `wheel` 事件，阅读器页面模式已经可以据此翻页。现有实现原先按“鼠标滚轮”处理，触控板的连续小增量和惯性会连续翻页；本次已改为手势识别：一次连续双指滑动只翻一页。

## 事件模型

| 输入 | 浏览器事件 | 说明 |
|---|---|---|
| 双指上下滑 | `wheel`，`deltaMode = 0`，小像素增量 | 手指抬起后仍有惯性事件 |
| 双指左右滑 | `wheel`，`deltaX` 为主 | 当前实现吞掉，避免 WebView 横向滚动或触发前进/后退 |
| 捏合缩放 | `wheel` + `ctrlKey = true` | 放行给 WebView2，不翻页 |
| 三指 / 四指手势 | 通常被 Windows 占用 | 应用收不到，不能作为阅读手势 |
| 触摸屏双指 | `pointerdown` / `touch` | 与触控板不是同一路径，不在本次范围 |

## 已实现行为

- 仅在 `page` 模式且 `reader.wheelTurn` 开启时拦截；`scroll` 模式保留原生滚动。
- 鼠标滚轮：`deltaMode !== 0` 或 `|deltaY| >= 40` 视为一格，立即翻页，320ms 冷却。
- 触控板：累计 `|deltaY|` 达到 48px 翻一页；一次连续手势最多翻一页，惯性不会继续翻。
- 手势结束判定：160ms 内没有新的 `wheel` 事件；结束后才允许下一次手势。
- `ctrl + wheel`（捏合）不拦截、不翻页。
- 横向双指滑动只 `preventDefault`，不执行翻页；后续可扩展为章节切换。
- 代码位置：`frontend/src/views/ReaderView.tsx` 的 “Page-mode wheel handling” 段。

## 限制

- 触控板惯性曲线由驱动决定，48px / 160ms / 320ms 是经验值，尚未提供灵敏度设置。
- 部分鼠标的“平滑滚动”也会产生小增量，会被当作触控板处理；行为仍然是一次手势一页，不会失控。
- 横向滑动目前不复用为章节切换，避免与系统/浏览器的横向手势冲突。
- 没有做硬件级自动化测试；需要在 Windows 10/11 精密触控板、普通鼠标、滚动模式下人工验证。

## 验证矩阵

- [ ] 双指慢速上滑 / 下滑：各翻一页，不连翻。
- [ ] 双指快速滑动并保持惯性：只翻一页。
- [ ] 连续两次间隔约 200ms 的滑动：翻两页。
- [ ] 鼠标滚轮单格：翻一页；快速滚轮不会一次跳多页。
- [ ] 捏合缩放：不翻页。
- [ ] 横向双指滑动：不翻页、不横向滚动。
- [ ] 上下滚动模式：双指滚动为原生平滑滚动。
- [ ] 关闭“滚轮翻页”后：页面模式不再响应滚轮/触控板翻页。
