## 1. 设计目标

### 一句话

**一个入口，三种动作：问书、进入书、改写书。**

- **问书**（问答）：只读，回答原文事实、定位情节。
- **进入书**（沉浸穿越）：进入某一幕，以角色视角体验，不改变原著。
- **改写书**（改写世界线）：做出选择，生成另一条世界线，选择必须被落实。

### 人类友好原则

1. **一屏一个主操作**：准备阶段只有一个「继续准备」；进入沉浸后只有「选择反应」；改写页只有「选择并继续」。
2. **先给原文，再给 AI**：任何时候原文都先出现，AI 生成不阻塞阅读。
3. **说人话，不说模型术语**：不出现 prompt、token、embedding；用「准备本书」「分析剧情」「生成主角体验」。
4. **每一步都能停**：索引、生成、世界线都能暂停/退出，已完成部分保留。
5. **失败给下一步**：错误必须带「重试 / 改设置 / 回到原文」中的至少一个动作。
6. **不假装确定**：AI 生成与原文视觉上必须分开；选项冲突、锚点压力、未解决线索都要明确提示。

## 2. 信息架构与入口

### 侧栏

```
阅读
  书架
  搜索
  统计

智能
  AI 书房          ← 唯一 AI 入口

设置
  同步书架
  账号
```

- 原「助手」与「穿越」合并为 **AI 书房**。
- 旧路由 `assistant` / `traversal` 保留一个版本作为别名，分别落到 `AI 书房 → 问答` / `AI 书房 → 沉浸`。

### 书籍右键菜单

保留两个直达动作，减少点击：

```
继续阅读
打开详情
────────
问这本书          → AI 书房 · 问答
进入这本书        → AI 书房 · 沉浸穿越（仅小说）
改写这本书        → AI 书房 · 世界线（仅小说，需完成世界设定）
────────
移动到分组
标记已读完
设为私密
移出书架
```

- 非虚构/教材/期刊/医学书：只显示「问这本书」；另外显示对应工具入口（如「知识地图」「刊物速览」）。
- 有声书/公众号：不显示 AI 入口。

### 书籍详情页

在「继续阅读 / 从头读 / 下载全书」之后，加一条 AI 操作带：

```
[问这本书] [进入这本书] [改写这本书]
或
[问这本书] [知识地图] [自测卷]
```

未完成索引时，按钮不隐藏，点击后直接跳到 AI 书房的「本书准备」并高亮缺失步骤。

### AI 设置入口

- 设置页 → **AI 服务**（唯一配置中心）。
- AI 书房右上角齿轮 → 跳到同一位置。
- 未配置时，AI 书房顶部显示一条引导条：「还没有连接 AI 服务 → 去设置」。

## 3. 视觉方向

### 主手法：深色书房里的纸页舞台

- 外层保持应用现有深色 chrome：`#12141a` / `#171a22` / `#1e2230`。
- AI 生成的内容放在**暖纸色舞台**上：`#efe7d7`，正文用宋体，形成「原文/演绎」与「系统 UI」的清晰分层。
- 系统操作使用蓝色 `#4d84ff`；锚点、冲突、承诺使用琥珀色 `#d9a441`；成功使用绿色 `#57c38a`。
- 第一眼焦点：**当前这本书**（书封 + 标题 + 类型 + 索引状态），其次才是能力卡片。

### 字体与尺寸

| 用途 | 字体 | 字号/行高 |
|---|---|---|
| UI | PingFang SC / Microsoft YaHei UI | 11–18px |
| 原文、AI 演绎 | Songti SC / Noto Serif SC | 13–17px / 1.85–1.95 |
| 提示、元信息 | UI | 10–11.5px |
| 代码/提示词 key | JetBrains Mono / Consolas | 10px |

### 状态颜色

- 可用：绿色 chip + 正常按钮。
- 需准备：琥珀 chip + 禁用按钮 + 「去准备」文字链。
- 生成中：蓝色 chip + 分阶段文案 + 进度条/骨架。
- 冲突：琥珀边框 + 说明，不用红色警报；红色只用于失败和删除。
- AI 生成：蓝色「AI 演绎 / AI 生成」chip；原文用左侧竖线与「原文」标签。

## 4. 屏幕设计

### 4.1 AI 书房总览

设计稿：[hub.png](screens/hub.png)

布局：

```
页面标题（AI 书房 + 一句话）
书籍条（书封 / 书名 / 作者 / 类型 / 缓存 / 索引状态 / 更换书籍）
┌───────────────────── 392px ─────────────────────┐  ┌──────────── 自适应 ────────────┐
│ 本书准备                                          │  │ 选择一种方式                    │
│  1 文本索引   ✓ 完成                              │  │ [问答] [沉浸穿越] [改写世界]     │
│  2 剧情索引   ● 18/42 章 · 约 2 分钟              │  │                                 │
│  3 世界设定   ○ 未建立                            │  │ 最近的世界线                     │
│  [继续准备] [暂停]                                │  │ 第 12 幕分叉 · ...               │
└───────────────────────────────────────────────────┘  └─────────────────────────────────┘
底部说明：故事穿越只对虚构叙事开放
```

交互规则：

1. **准备卡永远在最前**：即使用户点「问答」，也先看到索引状态。
2. **能力卡三态**：
   - 可用：主按钮可点。
   - 需准备：按钮禁用，chip 说明缺哪一步，卡片底部有「去准备」文字链。
   - 类型不适用：显示「仅小说可用」或「这本书不支持」，不显示按钮。
3. **一次只强调一个主按钮**：当前推荐动作使用蓝色实心，其余为描边。
4. **最近世界线**：最多 2 条，显示分叉幕、标题、幕数、相对时间；点击直接恢复。
5. **更换书籍**：只切换书名，不重置索引；切换后重新拉取准备状态。
6. **未配置 AI**：准备卡上方插入引导条，不显示能力按钮，只保留「去设置」。

引导文案：

- 未配置：「先连接一个 AI 服务，才能准备这本书。支持 DeepSeek、OpenAI、Ollama 等。」
- 未准备：「这本书还没准备。先建立文本索引，AI 才能引用原文。」
- 类型不适用：「《高等数学》被识别为教材，故事穿越不可用；可以使用知识地图或自测卷。」

### 4.2 本书准备（索引向导）

不单独做一页，作为 AI 书房左侧的准备卡 + 一个可展开的步骤面板。

三步：

| 步骤 | 内容 | 用户看到的状态 |
|---|---|---|
| 1 文本索引 | 分块、BM25、block 锚点 | `✓ 完成 · 286 段 · 12.4 万字` |
| 2 剧情索引 | 场景、摘要、人物、地点、POV | `● 正在分析剧情 · 18/42 章 · 约 2 分钟` |
| 3 世界设定 | 锚点、世界表、初始状态 | `○ 未建立 · 改写世界前需要确认` |

交互：

- **开始前**：显示预计调用量与时间；需要用户确认「会发送章节正文」。
- **进行中**：进度条 + 当前章节 + 阶段性文案 + 「暂停」；暂停后保留已完成章节。
- **失败**：显示失败章节数 + 「重试失败章节」，不重跑全书。
- **完成**：第 2 步变成「✓ 剧情索引完成 · 42 幕」；能力卡自动解锁。
- **过期**：章节更新或分块版本变化时，显示「索引已过期」+「重建」；依赖的能力变为不可用。

硬规则：

- 没有第 1 步，任何 AI 功能不可用。
- 没有第 2 步，沉浸/改写不可用。
- 没有第 3 步，改写不可用。
- UI 只负责解释；后端必须同样拒绝。

### 4.3 问答

沿用现有问答布局，但归入 AI 书房「问答」标签。

关键改动：

### 4.4 沉浸穿越

设计稿：[immersion.png](screens/immersion.png)
生成中：[immersion-loading.png](screens/immersion-loading.png)

定位：**进入原著，不改原著。**

布局：

```
顶部：← AI 书房 | 书名 · 第 N 幕 | 进度 | 视角选择 | 回到原文
┌──────────────────── 纸页舞台 760px ────────────────────┐ ┌──── 右栏 300px ────┐
│ 第 N 幕 · 标题                  [AI 演绎] [原文 1,240 字] │ │ 本幕信息             │
│ 原文摘录（可折叠）                                      │ │ 地点/时间/在场/情绪  │
│ AI 演绎 · 以林黛玉的视角                                │ │ 不会剧透             │
│ 叙述正文……                                              │ │ 阅读提示             │
│ 你会怎么反应？                                          │ └─────────────────────┘
│ [1 继续装睡] [2 睁开眼] [3 坐起来]                      │
│ 这一幕不会改变原著            查看原文  下一幕 →         │
└─────────────────────────────────────────────────────────┘
底部：← 上一幕 | AI 演绎，非原文 | 退出沉浸
```

交互：

1. **进入方式**：从 AI 书房「沉浸穿越」、书籍右键「进入这本书」、时间线某一幕「进入这一幕」。
2. **原文优先**：进入后立刻显示原文；AI 叙述流式追加，不遮住原文。
3. **视角**：默认主角；可切换「旁观者 / 指定角色」。切换会重新生成当前幕，旧版本可回看。
4. **反应选项**：2–3 个，只影响语气/对话/心理，不改变原著结果。选择后显示「已记录你的反应」，可「换一个反应」。
5. **回溯**：只回溯沉浸会话，不影响原著；「回到这一幕开头」清空本幕生成，保留已读进度。
6. **退出**：Esc 或「退出沉浸」；确认「已生成内容会保留，下次可以继续」。
7. **失败**：显示原文 + 「重试 / 只看原文」；不显示空白舞台。

键盘：

- `1/2/3` 选择反应
- `←/→` 上一幕/下一幕
- `Esc` 退出
- `Ctrl+Enter` 自定义反应（如果开放）

### 4.5 改写世界线

设计稿：[worldline.png](screens/worldline.png)

定位：**做出选择，生成另一条世界线；选择必须被落实。**

布局：

```
顶部：← AI 书房 | 世界线标题 | 进行中 | 第 3/5 幕 | 已自动保存 | 回到原著 | 导出
┌── 时间线 218 ──┐ ┌──────────── 主舞台 ────────────┐ ┌──── 右栏 272 ────┐
│ 第 11 幕 原著   │ │ 原著这里发生了什么             │ │ 世界状态           │
│ 第 12 幕 分叉点 │ │ 第 14 幕 · 雨夜里的选择        │ │ 银钱/声望/体力     │
│ 第 13 幕 已生成 │ │ [AI 生成] [已落实选择]         │ │ 道具               │
│ 第 14 幕 当前 ↺ │ │ 生成正文……                     │ │ 剧情锚点           │
│ 第 15 幕 未来   │ │ ✓ 本幕已落实：……               │ │ 剧情提示           │
│ 第 16 幕 收束   │ │ 接下来                          │ └────────────────────┘
│ [从这一幕重开]  │ │ [选择 1] [选择 2] [选择 3]      │
└─────────────────┘ └─────────────────────────────────┘
底部：或者，直接说出你想发生什么… [发送]
```

#### 分支

- 左栏时间线是**世界线**，实线；原著分叉点用琥珀节点 + 「分叉点」标签。
- 当前节点用蓝色节点 + 「当前」。
- 未来节点降低透明度，不提前透露标题。
- 顶部始终有「回到原著」，避免用户迷路。
- 多世界线：在 AI 书房「最近的世界线」列出；世界线页内可「另存为」再分叉，不覆盖原线。

#### 选项系统

每个选项卡包含：

- 选择文本（不超过 20 字）；
- 一句后果提示；
- 冲突标记（琥珀边框）：与哪个锚点冲突、可能收束；
- 选择后：卡片收起为「已承诺」条，本幕生成时显示「正在落实：……」

规则：

1. **选择先落账，再生成**：死亡、道具、关系等确定性效果先写入状态。
2. **承诺注入**：接下来 1–2 幕的生成提示词包含「本幕必须落实：……」。
3. **生成后校验**：未落实 → 显示「这一幕没有落实你的选择」+「重试 / 改写选择 / 回到原著」。
4. **冲突前置**：提交前提示，不让用户生成完才发现被拉回。
5. **自由输入是次要入口**：放在底部，不抢选项主位。

#### 回溯

- 当前节点右侧「↺ 回溯」，或左栏底部「从这一幕重开」。
- 点击后打开确认面板：

```
从第 14 幕重开？
将删除此后 2 幕（第 15–16 幕），原著不受影响。
[取消] [另存当前世界线] [从这里重开]
```

- 重开后保留：分叉点、第 12–13 幕、世界状态快照。
- 删除的幕不物理删除，标记为 `abandoned`，可通过「历史」找回（高级功能）。
- 回溯动画：时间线节点向上折叠 220ms，回到目标节点后弹出 toast「已回到第 14 幕」。

#### 剧情提示

右栏三块：

1. **世界状态**：3 条属性 + 道具 chips；点击「查看世界表」展开详情。
2. **剧情锚点**：下一条锚点、还有几幕、引力强度；文案强调「世界会尝试拉回，但允许不同路径」。
3. **剧情提示**：三条以内，区分：
   - 你已改变：……
   - 未解决：……
   - 下一幕可能：……（不是剧透，是当前张力）

提示只在用户选择后更新；不主动预测太远。

#### 生成中

- 选项提交后，按钮变为「正在推演世界线…」；
- 本幕区域显示：

```
正在检查你的选择…
正在推演世界线…
正在生成第 14 幕…
正在校验选择是否落实…
```

- 若校验失败：红色失败条 + 三个动作。
- 若与锚点冲突：琥珀警告条 + 「为什么」展开规则解释。

### 4.6 统一 AI 设置

设计稿：[settings.png](screens/settings.png)

入口：设置页 → AI 服务；AI 书房右上角齿轮直达。

分区：

1. **AI 服务**
   - 供应商预设：DeepSeek / OpenAI / Moonshot / 硅基流动 / Ollama / LM Studio。
   - 服务地址、API Key（掩码）、默认模型、快速模型。
   - 「测试连接」：只发一条极短消息，显示延迟与模型名。
2. **生成与检索**
   - 检索段落数、上下文扩展、温度、最大输出。
   - 流式输出、失败重试、JSON 模式优先。
3. **系统提示词**
   - 列表：问答、场景抽取、沉浸叙述、分支生成、选项生成、摘要、教材脑图、测试卷。
   - 每项显示 key + 版本 + 「使用默认 / 已自定义」。
   - 自定义后必须通过必填变量校验；提供「恢复默认」。
   - 「展开更多提示词」收纳低频项。
4. **数据与安全**
   - 允许发送正文片段、允许导入世界线包。
   - 日志隐藏正文与 Key；API Key 只存本机。
5. **本月用量**
   - 调用次数、token、预算进度；超预算后暂停生成，保留问答。

交互：

- 自动保存；顶部显示「设置会自动保存」。
- 修改提示词后提示「只影响新生成，不会改写已有世界线」。
- Key 不回显明文；复制按钮一次性显示。
- 连接失败：显示状态码 + 「检查地址 / Key」+「重试」，不弹大段错误。

## 5. 动画与加载文案

### 动效原则

- 微交互 120ms；常规 200ms；页面/场景进入 320ms。
- 缓动：`cubic-bezier(0.2, 0.8, 0.2, 1)`。
- 只动透明度、位移 4–8px、宽度；不做大幅缩放。
- 不用无限旋转 spinner 作为唯一反馈；必须有阶段文案。
- 尊重 `prefers-reduced-motion`：关闭位移、脉冲、骨架 shimmer，只保留淡入。

### 阶段文案

| 场景 | 阶段 | 文案 |
|---|---|---|
| 文本索引 | 1 | 正在读取章节… |
| 文本索引 | 2 | 正在切分段落… |
| 文本索引 | 3 | 正在建立文本索引… |
| 剧情索引 | 1 | 正在读取章节… |
| 剧情索引 | 2 | **正在分析剧情…** |
| 剧情索引 | 3 | 正在标注人物、地点与情绪… |
| 剧情索引 | 4 | 正在整理时间线… |
| 世界设定 | 1 | 正在提取关键事件… |
| 世界设定 | 2 | 正在建立世界状态… |
| 沉浸 | 1 | 正在进入第 12 幕… |
| 沉浸 | 2 | 正在读取场景与人物… |
| 沉浸 | 3 | **正在生成主角体验…** |
| 改写 | 1 | 正在检查你的选择… |
| 改写 | 2 | **正在推演世界线…** |
| 改写 | 3 | 正在生成第 14 幕… |
| 改写 | 4 | 正在校验选择是否落实… |
| 问答 | 1 | 正在检索原文… |
| 问答 | 2 | 正在组织回答… |
| 教材脑图 | 1 | 正在提取概念… |
| 教材脑图 | 2 | 正在生成脑图… |

文案规则：

- 动词开头，说“正在做什么”，不说“加载中”。
- 有总数时带进度：`18/42 章`；有预计时间时带「约 2 分钟」。
- 阶段切换用 6px 上移 + 200ms 淡入；不要整块闪烁。
- 可取消的任务始终显示「暂停 / 取消」。
- 失败文案：`第 18 章分析失败，其余章节已完成。[重试失败章节]`。

### 具体动效

| 元素 | 动效 |
|---|---|
| 准备步骤 | 当前步骤圆点脉冲环 1.8s；进度条轻微呼吸，不做无限冲刺 |
| 能力卡 | hover 上移 2px，180ms；禁用卡不位移 |
| 沉浸叙述 | 流式追加，光标 1.05s 闪烁；段落淡入 120ms |
| 反应选项 | 生成完成后逐条出现，间隔 40ms，位移 6px→0 |
| 选择提交 | 选项卡收起为「已承诺」条，220ms；状态条背景淡入 |
| 分支时间线 | 新节点出现时竖线向下绘制 320ms，节点 120ms 弹出 |
| 回溯 | 节点折叠 220ms；回到目标节点后 toast 240ms |
| 冲突提示 | 琥珀边框 1.2s 轻脉冲，最多 2 次；不闪红 |
| 成功 | 勾选路径绘制 240ms |
| 页面切换 | 内容淡入 + 8px 上移 240ms；不用翻页动画 |

## 6. 状态设计

| 状态 | 表现 | 主操作 |

| 未配置 AI | 顶部引导条 + 能力按钮隐藏 | 去设置 |

## 10. 设计取舍

- **没有把「问答 / 沉浸 / 改写」做成三个侧栏入口**：它们共享同一本书、同一份 AI 配置、同一套索引，合并后认知负担更低。
- **没有把改写做成聊天框**：选项是承诺，聊天是补充；主位必须是可校验的选项。
- **没有把原文和 AI 文本混在一起**：纸页舞台 + AI chip + 原文标签，避免用户误把演绎当原文。
- **没有用红色表达锚点冲突**：冲突不是错误，是选择代价；红色只留给失败。
- **没有做无限 spinner**：每个等待都有阶段、进度和取消。
